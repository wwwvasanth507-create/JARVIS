# JARVIS Interactive Terminal Chat Interface

## Overview
The terminal chat interface (`src/jarvis/ui/chat.py`) serves as the primary human-to-JARVIS interface for the Boss.

## Features
- **Local Command Interception**: Command inputs (e.g. `exit`, `/status`, `/help`, `/clear`) are intercepted locally and never passed to the LLM.
- **Progressive Streaming**: Tokens generated by the local GGUF model stream progressively to stdout.
- **Sentence-Level Streaming TTS**: As token chunks complete sentences, TTS synthesis speaks them immediately.
- **Typed Message History**: Tracks `UserMessage` (with source `chat` or `voice`), `AssistantMessage`, and `SystemMessage`.
- **Bounded Context Protection**: Integrates with `ContextManager` to prune old messages when context budget (e.g., 2048 tokens) is exceeded.

## Available Terminal Commands
| Command | Description |
|---------|-------------|
| `exit`, `quit`, `/quit` | Exits the JARVIS session cleanly |
| `clear`, `/clear` | Clears terminal screen and conversation history |
| `status`, `/status` | Displays system status, hardware info, and voice readiness |
| `/help` | Lists available CLI commands |
| `/chat` | Switches operation to Text Chat mode |
| `/voice` | Switches operation to Voice mode |
| `/hybrid` | Switches operation to Hybrid mode |
| `/listen` | Triggers push-to-talk microphone capture |

## Launching
```bash
python scripts/jarvis_cli.py
```

# JARVIS Computer Control Architecture

## Overview
The **JARVIS Computer Control Subsystem** (`src/jarvis/computer/`) enables controlled local operating system interaction (mouse movement, mouse clicks, scrolling, text typing, hotkeys, screenshots, and window management).

## Architecture & Security Pipeline
JARVIS never executes unrestricted operating system commands or arbitrary Python code generated by LLMs. All computer actions follow a strict security pipeline:

```text
JARVIS Brain
      ↓
Tool Request (Structured JSON)
      ↓
Tool Registry (`src/jarvis/tools/`)
      ↓
Permission Evaluator (`src/jarvis/security/permissions.py`)
      ↓
Computer Controller (`src/jarvis/computer/factory.py`)
      ↓
Operating System (Win32 API)
      ↓
Observation & State Verification
      ↓
JARVIS Response
```

## Platform Subsystem Layout
- **`ComputerController`** ([base.py](file:///c:/ll/JARVIS/src/jarvis/computer/base.py)): Abstract interface defining mouse, keyboard, screenshot, and window management methods.
- **`ComputerControllerFactory`** ([factory.py](file:///c:/ll/JARVIS/src/jarvis/computer/factory.py)): Detects host OS (`platform.system()`) and returns `WindowsComputerController`.
- **`WindowsComputerController`** ([windows/controller.py](file:///c:/ll/JARVIS/src/jarvis/computer/windows/controller.py)): Native Windows implementation combining mouse, keyboard, screen, and window managers with non-interactive desktop session fallbacks.

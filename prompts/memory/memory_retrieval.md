# Memory Retrieval Guidelines

Rules for querying personal memory and knowledge:
1. **Precedence Tiering**: Respect memory hierarchy (User Instruction > Task Scope > Project Scope > App Scope > Global Preference > Weak Inference).
2. **Privacy Redaction**: Never load or return stored passwords, secret tokens, or private payment data.
3. **Relevance Filtering**: Retrieve only topically relevant facts and knowledge graphs bounded to the active context.
4. **Provenance Detail**: Detail source recency and confidence level when summarizing remembered information.
